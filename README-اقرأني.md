# MMY.YE — بناء ملف ويندوز (EXE) وأندرويد (APK) عبر GitHub

## الخطوات
1. أنشئ مستودعًا جديدًا على GitHub (Repository) — خاص أو عام.
2. ارفع **محتويات** هذا المجلد كما هي (مع مجلد `.github` المخفي) إلى الفرع `main`.
3. افتح تبويب **Actions** في المستودع، وسيبدأ البناء تلقائيًا (أو اضغط Run workflow).
4. بعد 5–10 دقائق افتح التشغيلة المكتملة، ونزّل من قسم **Artifacts**:
   - `MMY.YE-windows-exe` ← ملف التثبيت `MMY.YE-Setup-1.0.0.exe` + نسخة محمولة Portable
   - `MMY.YE-android-apk` ← ملف `app-debug.apk`

## التثبيت
- ويندوز: شغّل ملف Setup. قد تظهر شاشة SmartScreen لأن الملف غير موقّع: اضغط "More info" ثم "Run anyway".
- أندرويد: انقل الـ APK للجوال وافتحه، وفعّل "التثبيت من مصادر غير معروفة" إن طُلب.

## ملاحظات
- التطبيق يعمل بدون إنترنت. الخطوط فقط (Google Fonts) تحتاج إنترنت أول مرة، وإلا يُستخدم خط النظام.
- الـ APK الناتج بتوقيع تجريبي (debug) ويصلح للتثبيت المباشر، أما للنشر على Google Play فيلزم توقيع release.
- الدخول بالبصمة / Windows Hello يعتمد على WebAuthn، وقد لا يعمل داخل نسخة EXE أو APK. الدخول بكلمة المرور يعمل دائمًا.
- كلمة المرور الافتراضية admin / 1234 — غيّرها فور أول دخول.
